1️⃣ Authentication
POST /signup  (DONE)                  → user signup
POST /login     (DONE)                 → user login (email + password)
POST /login/otp                 → login with OTP (email or mobile)
POST /password/forgot           → send reset password email
POST /password/reset            → reset password using token

GET /auth/google              → Redirect to Google login
GET /auth/google/callback     → Google callback, verify, create JWT

2️⃣ Products (User)
GET /products                   → get all products (search & filter via query)
GET /products/:productId        → get single product details

3️⃣ Profile
GET /profile     (DONE)                → view user profile
PUT /profile    (DONE)                 → update user details
PUT /profile/password (DONE)           → change password

4️⃣ Cart
GET /cart                       → view cart
POST /cart/:productId           → add product to cart
PUT /cart/:productId            → update/remove product from cart

5️⃣ Orders / Buy / Payment
POST /orders                    → Place order (cart or single product) + payment type
GET /orders                     → Get user order history
PUT /orders/:orderId/payment    → Update payment status (success/failed)


6️⃣ Product Management (Admin)
POST /products                  → add product
PUT /products/:productId        → update product
DELETE /products/:productId     → delete product
